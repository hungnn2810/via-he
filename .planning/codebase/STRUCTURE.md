## Directory Purposes

**`server/src/`:**
- Purpose: All game rules and the network boundary.
- Contains: Flat module-per-system TypeScript files, one subdirectory `rooms/`.
- Key files: `index.ts`, `rooms/StreetRoom.ts`, `schema.ts`, `data.ts`, `profile.ts`.

**`server/test/`:**
- Purpose: Headless verification of rule modules and whole-economy simulation.
- Contains: One `.ts` file per system, each wired to an `npm run test:*` script and run with `tsx`.
- Key files: `simulation.ts` (default `npm test`), `world.ts`, `market.ts`, `season.ts`, `goods.ts`.

**`server/data/`:**
- Purpose: Content that can change without a code deploy.
- Contains: `dialogues.json` (events JSON is also read from here when present).

**`server/public/`:**
- Purpose: Static pages served by Express.
- Contains: `admin.html`.

**`client/Assets/Scripts/`:**
- Purpose: The entire client. No prefabs, no authored scenes.
- Contains: Networking, DTOs, generated schema, sprite and audio helpers. The presentation layer (widget kit, screens, street scene, character composition) is deleted and awaiting the rewrite.
- Key files: `Network.cs`, `Models.cs`, `Schema/StreetState.cs`, `SpriteLibrary.cs`.

**`client/Assets/Resources/Sprites/`:**
- Purpose: Runtime-loaded sprite set plus the `sprites.txt` / `street_sprites.txt` manifests (`name, pivotX, pivotY, left, bottom, right, top`, first line `ppu,200`).
- Contains: Currently emptied; regenerate from `client/Tools/sprites.js`, never hand-edit the manifests.

**`client/Tools/`:**
- Purpose: Art generation and import pipeline, run outside Unity.
- Contains: `sprites.js` (Canvas 2D drawing + `add()` manifest), `export-runner.mjs` / `export-server.mjs` / `export.html` (headless export), `cut_street.py` (slices `street_source*`), `concept/` style studies.

**`docs/client/`:**
- Purpose: The written form of the three contracts that used to live only in the deleted client code. Treat as the specification for the rewrite.

**`tools/`:**
- Purpose: Repo-level maintenance scripts, run with plain `node`.

**`.agents/skills/` and `.claude/skills/`:**
- Purpose: Task-specific agent skills (`add-product`, `add-event`, `add-quest`, `balance`, `draw-sprite`, `export-sprites`, `edit-schema`, `simulate-economy`, `smoke-test-game`, `verify-protocol`).
- Rule: Edit under `.agents/skills/`, then run `node tools/sync-skills.mjs`.

## Key File Locations

**Entry Points:**
- `server/src/index.ts`: HTTP + WebSocket boot, `npm start` (port 2567 or `$PORT`).
- `server/src/rooms/StreetRoom.ts`: Room lifecycle and all message handlers.
- `start-server.bat`: Windows launcher.
- Client bootstrapper: none — the old `Game.Boot()` was deleted and must be rebuilt (Wave 1–3 of `docs/client-remaster-plan.md`).

**Configuration:**
- `server/package.json`: scripts, dependencies, `schema-cs` codegen command.
- `server/tsconfig.json`: TypeScript settings.
- `client/Packages/manifest.json`: Unity package set.
- `client/ProjectSettings/`: Unity project settings (canvas scaler target was 1280x720).
- Environment: `PORT`, `DATA_DIR`, `TOKEN_SECRET`, `ADMIN_TOKEN` (no `.env` file in the repo).

**Core Logic:**
- `server/src/data.ts`: every price, unlock level and `BALANCE` constant.
- `server/src/profile.ts`: persistent player shape, SQLite tables, tokens, `GameError`.
- `server/src/world.ts`: land, crops, buildings, cooking, professions, deliveries, wages.
- `server/src/schema.ts`: the synced state contract.

**Testing:**
- `server/test/*.ts` via `npm test` / `npm run test:<system>`.
- `.claude/skills/smoke-test-game/`, `.claude/skills/verify-protocol/` for end-to-end gates.

**Generated artefacts (never hand-edit):**
- `client/Assets/Scripts/Schema/*.cs` ← `npm run schema-cs`.
- `client/Assets/Resources/Sprites/*.png` + `sprites.txt` ← `client/Tools/sprites.js` export.
- `docs/client/protocol.md` ← `node tools/dump-protocol.mjs`.
- `.claude/skills/**` ← `node tools/sync-skills.mjs`.

## Naming Conventions

**Files:**
- Server: lowercase single-word modules named after the system — `market.ts`, `regulars.ts`, `season.ts`. Rooms are PascalCase: `rooms/StreetRoom.ts`.
- Client: PascalCase matching the type inside — `Network.cs`, `SpriteLibrary.cs`, `Schema/StreetState.cs`. Each `.cs` has a tracked `.cs.meta`.
- Tools: kebab/lowercase with explicit extension — `dump-protocol.mjs`, `cut_street.py`.
- Docs: lowercase-kebab — `client-remaster-plan.md`, `sprite-names.md`.

**Directories:**
- Lowercase for server and tooling (`src`, `rooms`, `test`, `data`, `tools`, `docs/client`).
- Unity convention PascalCase under `client/` (`Assets`, `Scripts`, `Editor`, `Resources`, `Packages`, `Tools`).

**Identifiers:**
- English everywhere — classes, functions, fields, string ids, message types, routes, JSON keys, DB tables, asset names.
- Player-facing text stays Vietnamese, in string literals only.
- C# namespace `ViaHeOnline`, generated schema namespace `ViaHeOnline.Schema`.
- Messages are lowerCamelCase verbs (`openStall`, `claimSeasonTier`); HTTP routes are `/api/<noun>`; data ids are snake_case (`green_sunday`, `plastic_sandals`).
- Sprites are `<category>_<id>` built from server ids: `counter_<product.id>`, `wear_<wearable.id>`, `building_<type>`, `bg_land_<district>`, `deco_<id>`, `vehicle_<id>`, `npc_*` (the `npc_` prefix means "reacts to taps").

## Where to Add New Code

**New gameplay rule or system:**
- Rules: a new `server/src/<system>.ts` exporting functions over `Profile`, taking `now = Date.now()`.
- Numbers: `server/src/data.ts` (`BALANCE` or the relevant catalog table) — never inline.
- Wire-up: register the message in `server/src/rooms/StreetRoom.ts` via the `handle(...)` wrapper.
- Tests: `server/test/<system>.ts` plus a `test:<system>` script in `server/package.json`.

**New synced field:**
- `server/src/schema.ts`, then `cd server && npm run schema-cs` to regenerate `client/Assets/Scripts/Schema/`. Use the `edit-schema` skill.

**New message:**
- Handler in `server/src/rooms/StreetRoom.ts` → DTO in `client/Assets/Scripts/Models.cs` → routing/`Send` in `client/Assets/Scripts/Network.cs` → `node tools/dump-protocol.mjs` to refresh `docs/client/protocol.md` → run the `verify-protocol` skill.

**New HTTP route:**
- Inside the `express:` callback in `server/src/index.ts`; gate with `verifyToken` (player) or `isAdmin` (admin).

**New client screen / widget (rewrite):**
- `client/Assets/Scripts/` following the wave order in `docs/client-remaster-plan.md`: `Theme.cs` + `client/Tools/theme.js`, a `Depth.Of(y)` helper, pooled uGUI + TextMeshPro widgets, then screens.
- Copy the Vietnamese strings, state reads, messages and unlock conditions verbatim from `docs/client/screens.md`.
- Reproduce the scale, slot/lot layout, ground bands, depth sort and character layer order exactly as in `docs/client/world.md`.

**New sprite:**
- Draw it in `client/Tools/sprites.js` and register it with `add()` (the `draw-sprite` skill), export to `client/Assets/Resources/Sprites/` (the `export-sprites` skill), which also writes the `sprites.txt` row. Keep every existing id: renaming breaks the runtime lookup with only a warning.

**New product / event / quest:**
- Use the matching skill — each touches several files in a fixed order: `add-product`, `add-event`, `add-quest`.

**Shared utilities:**
- Server: add to the owning system module; `data.ts` for constants, `profile.ts` for profile-shaped helpers. There is no `utils.ts`.
- Client: a small focused file under `client/Assets/Scripts/`; keep `SpriteLibrary.Get(name)` the single sprite call site so the backing store can change.

## Special Directories

**`client/Assets/Scripts/Schema/`:**
- Purpose: C# mirror of `server/src/schema.ts`.
- Generated: Yes (`npm run schema-cs`).
- Committed: Yes.

**`client/Assets/Resources/Sprites/`:**
- Purpose: Runtime sprite set and its manifests.
- Generated: Yes (from `client/Tools/sprites.js` / `cut_street.py`).
- Committed: Yes, including `.meta` files.

**`.claude/skills/`:**
- Purpose: Claude Code copy of the shared skills.
- Generated: Yes (`node tools/sync-skills.mjs` from `.agents/skills/`).
- Committed: Yes.

**`server/data/`:**
- Purpose: Hot-reloadable content (`dialogues.json`).
- Generated: No.
- Committed: Yes.

**`$DATA_DIR` (default `server/data`-adjacent `data/`, created at runtime):**
- Purpose: `game.db` SQLite database and `token-secret.txt`.
- Generated: Yes, at first run.
- Committed: No.

**`server/node_modules/`, `node_modules/`, `client/Library/`:**
- Purpose: Dependencies and the Unity import cache.
- Generated: Yes.
- Committed: No.

**`client/Tools/concept/`:**
- Purpose: Three art-direction studies (`concept-style-1-hom-hinh`, `-2-moc-mac`, `-3-gen-z`); one must be chosen before the sprite catalog is regenerated.
- Generated: No.
- Committed: Yes.

**`.planning/`:**
- Purpose: GSD planning artefacts, including this codebase map.
- Committed: Yes.
